# Sega - Chihiro

Thumbnails for the Sega Chihiro games of [gameflix](https://wizzardsk.github.io), laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails) (`Named_Boxarts`, `Named_Logos`), named after the netboot images of the [ChihiroNetboot](https://archive.org/details/ChihiroNetboot) item.

Flyers (as boxarts) from the [Arcade Database](https://adb.arcadeitalia.net/), logos from libretro-thumbnails' MAME repository. There are no snaps or titles yet: MAME does not run Chihiro games, so the Arcade Database has only black or garbled screens for them.
